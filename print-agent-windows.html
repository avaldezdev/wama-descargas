Print Agent para Windows

Imprime las comandas de Wama-SIS directo en las impresoras de cocina, barra o cada estación desde la notebook o PC en la que se vende, sin pasar por el diálogo de impresión del navegador.

La comanda sale aunque ningún celular tenga el agente abierto. Puede funcionar junto con Print Agent para Android en el mismo local: cada comanda sale una sola vez.

Última versión
Descargar para Windows
Windows 10 u 11. No necesita permisos de administrador ni tener Java instalado.

Cómo instalarlo

  1. 1

    Instalá

    Abrí WAMA-Print-Agent-Setup.exe y seguí los pasos. Si aparece "Windows protegió su PC", tocá Más información y después Ejecutar de todas formas.

    Para actualizar, instalá la versión nueva encima: cierra la anterior y conserva la configuración.
  2. 2

    Configurá

    Se abre la configuración con los mismos datos que en Android: servidor, token (uno propio para esta PC), impresora por defecto y ancho de papel. Tocá Probar conexión, tildá Agente activo y Guardar.

  3. 3

    Listo

    • El agente queda como un círculo verde junto al reloj. Si está escondido, abrí la flechita ^ y arrastralo a la barra.
    • Arranca solo al iniciar Windows. Si una impresora falla, se pone rojo y suena una alarma.
    • Para desinstalarlo: Configuración › Aplicaciones instaladas › WAMA Print Agent.
¿Primera instalación en un local? Antes hay que preparar Wama-SIS (módulos, impresoras, estaciones y productos). Seguí el checklist completo en PDF.
